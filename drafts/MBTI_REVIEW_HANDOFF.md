# 청라 MBTI 2022 개편 — 배포 전 검토본

2026-11-16 사용자 배포 승인. 서버 스키마와 20개 자료 등록 완료, 240개 항목의 본문 해시가 검토본과 모두 일치함. 운영 배포 기록은 FEATURE_STATE.md 참고.

## 반영 범위

- 마지막 MBTI 유형 하위 메뉴만 기질·유형별 MBTI 학습법으로 재구성.
- MBTI 학습법 소개, MBTI 여섯 그룹 학습 성향, 학부모 MBTI 학습지도 안내의 문서·데이터는 유지.
- NF/NT/SJ/SP 종합 4개와 유형별 16개, 각 12개 항목. 제목·본문은 제공 PDF 기준.
- 1~4 성향·운영 / 5~9 과목 / 10~12 조언·상담으로 빠르게 찾기. 기질 카드에서 네 유형과 종합편을 왕복.
- 내 MBTI 저장 및 기존 학생별 학습 처방 유지. 처방 참고 자료는 새 문서의 4·12번 항목 사용.
- 문서/항목 편집, 저장, 삭제→휴지통, 복원, 영구삭제, 휴지통 비우기. 기존 원장·실장 MBTI 권한 유지.
- 전체/항목별 인쇄·PDF. 모바일 공통 PDF 생성·공유 버튼 재사용.

## 원문 변환·검증

`data/mbti-library-2022.json`에 20개 문서와 원본 파일명·SHA256·페이지 수 기록.
PDF의 16.5pt 항목 제목으로 12개를 분리하고 표는 엄격한 선 감지로 추출.
머리말/꼬리말(6pt)을 제외한 모든 문자의 다중집합을 대조해 누락·중복 없는 것을 확인.
원본의 오탈자나 `(초안)` 표시는 임의로 고치지 않음. 표 안의 원본 줄바꿈도 유지.

## 배포 후가 아닌, 지금 검증된 부분

- 로컬 DB: 권한, 충돌, 문서/항목 휴지통 전체 흐름, 휴지통 목록 변경 시 비우기 차단.
- 영구삭제는 본문을 제거하고 tombstone을 유지. seed 재실행 시 삭제 자료가 부활하지 않음.
- DOM: 4기질/16유형/240항목, 안전한 표 렌더, 내 유형 저장, 편집 취소, 계정 변경 응답 무시.
- PDF: ENFP 전체 14쪽, SJ 전체 8쪽 A4 생성 및 마지막 문장 확인. 한글·표 첫/마지막 페이지 렌더 검사.
- 모바일 공유는 기존 공통 PDF 기능의 모의 API 테스트를 재사용. 실제 iPhone/iPad 저장은 실기기 확인 필요.
- 브라우저 실행 제약으로 실제 화면 스크린샷 검증은 하지 못함. 반응형 CSS와 DOM 검증 완료.

## 승인 후 적용 순서

1. main의 최신 변경을 비교하고 이 브랜치와 병합 충돌을 점검.
2. `drafts/mbti-library-schema.sql` 적용. private 테이블은 직접 접근 차단, RPC는 승인된 MBTI 관리자만 호출.
3. `python scripts/build-mbti-seed.py /tmp/mbti-library-seed.sql` 실행 후 seed SQL 적용. ON CONFLICT DO NOTHING.
4. Supabase 보안/성능 advisors 확인 및 시험용 승인 계정으로 RPC 검증. 실제 학생 계정 위장 금지.
5. 새 프런트엔드 main 반영·배포. 나머지 세 MBTI 메뉴·학생별 처방·모바일 PDF 경로 확인.
6. 데이터 보존을 위해 새 테이블과 기존 자료를 삭제하는 rollback은 사용하지 않음. 필요 시 프런트엔드만 복귀.
