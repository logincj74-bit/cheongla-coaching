원장: 공통 + 청라생활(청라근무일지, 상담·신규등록카드, 일일학습계획표 확인, 휴지통 관리) + 나의 MBTI학습법(원장 전용, 인쇄/PDF).
실장: 공통 + 청라생활(청라근무일지, 상담·신규등록카드, 일일학습계획표 확인) + 내 전화번호 등록·수정.
학부모: 공통 + 청라생활(일일학습계획표) + 내 전화번호 등록·수정.
학생: 공통 + 청라생활(일일학습계획표) + 내 전화번호 등록·수정.
계정·로그아웃·승인·알림 등 필수 기반 서비스는 메뉴 축소와 별도로 보존.

## 학습계획표
학생 제출 -> 학부모 알림 -> 학부모 확인 완료(확인 시각 기록).
권고: 작성일 + 7일에 보관 상태로 전환. 학부모 미확인도 기록하고 운영자에게 요약 알림. 자동 영구삭제 금지.
휴지통은 원장만 영구삭제 가능. 학생/학부모 본인 기록 권한 RLS 확인. 인쇄/PDF 유지.
보관 및 영구삭제 기한은 실제 운영·개인정보 보존 정책을 검토한 후 확정. 저장 용량은 Supabase 사용량·파일 크기 측정으로 판단.

## 근무일지
월~일 주간 보기: 날짜별 일지를 한 화면에 세로로 연결, 스크롤·인쇄·PDF, 기존 일별 작성/수정 기능 유지.
작성/수정 알림은 근무자별 수신 설정: 평일 실장 월~금 15:30~23:00, 주말 실장은 실제 근무 일정에 따라. 원장 기본 수신.
알림 잠시 끄기, 다음 근무 시작에 자동 재개, 긴급/일반 알림 구분. 알림이 꺼져도 앱 알림함에는 기록 유지.
알림 발송 전 수신자의 근무시간·설정 서버 측 검사, 반복 수정 알림 묶음 처리.
