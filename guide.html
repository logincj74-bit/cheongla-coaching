01 가입과 자녀 연결

학생 · 학부모 / 승인 담당자
첫 화면 → 로그인하기 → 회원가입

학생과 학부모는 각자 계정을 만듭니다. 가입 후 학원 이용 승인을 받아야 회원 서비스를 이용할 수 있습니다. 학부모 계정에는 관리자가 자녀를 연결해야 신청과 비용 내역이 표시됩니다.

  1. 01 가입 정보 입력
  2. 02 승인 확인
  3. 03 연락처 · 자녀 확인

1. 회원가입

이름·이메일·휴대전화번호와 역할을 입력하고 비밀번호를 두 번 입력합니다. 두 비밀번호가 일치하는지 확인한 뒤 가입합니다.

2. 학원 승인 확인

승인 대기라면 학원에 알려 주세요. 담당자는 회원 승인 메뉴에서 이름과 역할을 확인하고 승인합니다. 화면이 그대로라면 승인 상태 새로 확인을 누릅니다.

3. 연락처와 자녀 확인

내 연락처에서 번호를 확인합니다. 학부모는 연결된 자녀를 확인하고, 자녀가 없거나 잘못 연결되면 학원에 연결 수정을 요청합니다.

계정을 잊어도 새로 가입할 필요가 없습니다. 학원에 기존 계정 복구를 문의하세요.

02 메뉴와 공지 확인

모든 승인 회원
로그인 → 업무 메뉴 열기 · 다른 업무로 이동

선택한 업무만 표시되므로 화면을 길게 내려가며 메뉴를 찾지 않아도 됩니다. 청라데스크는 신청·운영 업무를, 청라소식은 원장 공지와 입시 정보를 찾는 출발점입니다.

  1. 01 업무 메뉴 펼치기
  2. 02 원하는 업무 선택
  3. 03 공지 · 알림 확인

1. 업무 선택

업무 메뉴를 펼쳐 원하는 항목을 누릅니다. 선택하면 메뉴가 접히고 해당 업무만 보입니다. 다른 업무로 이동할 때 다시 펼칩니다.

2. 두 공지 구분

청라소식의 원장 공지는 학습·운영 방향 안내입니다. 청라데스크의 공지 등록 · 관리는 실장 업무 공지입니다. 공지 화면에서는 채널과 전체·학생·학부모 대상을 확인합니다.

3. 처음 화면과 알림

하단 청라 첫 화면으로 메인에 돌아갑니다. 뒤로 가기는 직전 화면으로 이동합니다. 알림함에서는 본인에게 해당하는 신청·답변·공지 알림을 확인합니다.

원장·실장과 학생·학부모의 메뉴는 권한에 따라 다릅니다. 로그인 전 신규 상담은 회원 업무와 별도입니다.

03 학생과 학부모의 도시락 신청

학생 · 연결된 학부모
청라데스크 → 도시락 신청

학생 계정은 본인의 이름으로, 학부모 계정은 선택한 자녀의 이름으로 신청합니다. 학생과 학부모가 같은 신청서를 함께 확인하므로 중복으로 따로 신청하지 않습니다.

  1. 01 신청 월 확인
  2. 02 점심 · 저녁 체크
  3. 03 제출 · 신청완료

1. 월과 자녀 선택

신청 월과 제출기한을 확인합니다. 학부모는 먼저 신청할 자녀를 고릅니다. 해당 월 신청서가 없으면 학원에 개설을 문의합니다.

2. 날짜별 식사 체크

원하는 날짜의 점심·저녁을 각각 체크합니다. 상단 점심·저녁·합계 수량이 자동 계산됩니다. 전달할 사항은 개인 비고에 씁니다.

3. 제출 후 다시 확인

신청서 제출 버튼을 누른 뒤 신청완료 표시를 확인합니다. 수정 가능 기간에는 체크를 바꾼 뒤 다시 저장합니다. 0개 제출은 확인창에서 의도한 신청인지 다시 확인합니다.

체크만 하고 나가면 저장되지 않습니다. 당일 식사 취소는 불가하며 전날 취소도 학원 안내와 마감 상태를 확인하세요.

04 도시락 운영과 월말 청구

원장 · 실장
청라데스크 → 도시락 신청 현황

원장과 실장은 신청하지 않습니다. 월별 신청서를 설정하고 학생별 수량과 월말 청구를 관리합니다. 식사 수량만 확인한 상태와 학생·학부모에게 청구를 게시한 상태를 구분합니다.

  1. 01 신청서 설정
  2. 02 수량 · 조정액 확인
  3. 03 청구 저장 · 게시

1. 월별 신청서 준비

관리자 · 월별 신청서 설정에서 대상 월·제출기한·단가·공통 비고를 저장합니다. 학생용 양식 미리보기로 날짜와 안내를 확인합니다.

2. 신청 명단 검토

신청 명단을 펼쳐 학생별 점심·저녁 날짜와 비고를 확인합니다. 현재 설정 단가로 금액을 계산합니다. 기본 예시는 1식 7,500원이며 실제 월 설정을 우선합니다.

3. 정산 저장과 게시

학생별 납부기한과 정산 조정액을 저장합니다. 전월 취소분 차감은 음수, 추가는 양수입니다. 금액을 검토한 후 청구를 게시하고 청구 · 입금 관리에서 수납을 확인합니다.

신청이 바뀌면 청구를 다시 저장·검토해야 합니다. 원장은 테스트 신청을 확인 후 삭제할 수 있으며, 게시·수납된 기록은 연결 상태에 따라 처리 제한이 있습니다.

05 모의고사 등록과 신청

원장 · 실장 / 학생 · 학부모
직원 청라데스크 → 모의고사 공지등록 · 신청명단

관리자가 시험을 등록하고 신청을 열어야 학생과 학부모에게 신청 버튼이 보입니다. 시험 구분만 있고 게시된 시험이 없는 경우에는 신청할 수 없습니다.

  1. 01 시험 저장 · 신청 열기
  2. 02 신청완료 · 명단 확인
  3. 03 응시료 입력 · 게시

1. 시험 등록

시험 구분·제목·시험일·신청 마감·게시 상태를 확인하고 시험 저장을 누릅니다. 마감은 한국 시간 기준으로 입력합니다. 날짜 오류는 표시된 입력란을 수정합니다.

2. 신청과 명단 확인

학생·학부모는 청라데스크 → 모의고사 신청에서 시험을 고르고 신청완료를 확인합니다. 학부모는 연결된 자녀를 선택합니다. 직원은 아래 신청 명단에서 신청·미신청 상태를 확인합니다.

3. 응시료 안내

응시료 안내에서 시험을 선택해 가변적인 금액과 납부기한을 직접 입력합니다. 설정 저장 → 신청자 초안 생성 → 금액 확인 → 게시 순서로 진행합니다.

구분: 대성 더 프리미엄 / 시대인재 서프 / 한국교육과정평가원 6월 / 9월 / 기타. 신청 취소·재신청은 마감과 시험 상태에 따릅니다.

06 학원비와 스쿨 기간 계산

원장 · 실장 / 학부모 확인
청라데스크 → 학원비 안내

학생 유형과 등록 정보를 먼저 저장한 뒤 청구 초안을 계산합니다. 윈터·썸머는 시작일과 종료일을 고정하고 제외 날짜를 별도로 선택합니다. 제외 날짜 때문에 종료일이 자동으로 늘어나지는 않습니다.

  1. 01 등록 정보 저장
  2. 02 기간 · 제외일 입력
  3. 03 초안 확인 · 게시

1. 학생과 유형 저장

청구 월·학생·학원비 유형·최초 등록일·기본 원비를 확인하고 등록 정보 저장을 누릅니다. 재수생 450,000원, 재학생 200,000원, 공시생 350,000원, 윈터·썸머 610,000원이 기준입니다.

2. 기간과 제외 날짜 입력

기간별 계산에서는 시작일·종료일을 모두 포함하며 주말도 포함합니다. 학교 등교 등 제외할 날짜를 추가합니다. 윈터·썸머의 일별 계산은 사용자가 정한 하루 20,000원을 적용합니다.

3. 초안 검토 후 게시

납부기한을 넣고 초안 계산·저장을 누릅니다. 이용일수·금액·예약금 차감 여부를 확인한 후 게시합니다. 예약금 100,000원은 통장 확인 후 같은 스쿨 시즌에 한 번만 차감합니다.

표시 일요금: 재수생 15,000원 / 재학생 6,667원 / 공시생 11,667원. 일반 유형의 일할 금액은 월 원비÷30 기준 서버 계산 결과를 확인하세요. 안내 새로고침은 작성 내용을 초기화하므로 주의하세요.

07 납부 알림과 입금 확인

학생 · 학부모 / 원장 · 실장
청라데스크 → 납부 · 입금 확인 또는 청구 · 입금 관리

학원비·응시료·도시락비를 청구 월과 비용 구분으로 모아 확인합니다. 가족이 보낸 입금 알림은 확인 요청입니다. 실제 통장 대조 후 직원이 처리해야 납부 완료로 관리됩니다.

  1. 01 입금 알림 남기기
  2. 02 통장 대조 · 확인
  3. 03 완료 또는 재확인

1. 가족의 납부 알림

게시된 청구의 금액과 계좌를 확인하고 학생 이름으로 입금합니다. 앱에서 입금자명·입금일 등 요청 항목을 입력해 입금 알림을 남깁니다. 문자앱 연결 시 마지막 전송은 직접 누릅니다.

2. 학원의 통장 대조

직원은 청구 월·비용 구분·상태로 확인 대상을 좁힙니다. 학생 이름과 실제 입금 내역을 대조한 뒤 납부 완료 또는 재확인 상태로 처리합니다. 이름이 다른 입금은 가족에게 확인합니다.

3. 미납 안내

미납 대상과 금액·연락처를 확인하고 문자 내용을 미리 봅니다. 연결된 학부모를 확인한 뒤 문자앱에서 전송합니다. 확인 대기·납부 완료 건을 미납으로 재촉하지 않도록 상태를 먼저 확인합니다.

원장이 통장을 확인한 명단 등록

청구 · 입금 관리에서 청구 월·비용 종류를 선택하고 원장 통장 확인 · 입금완료 등록을 펼칩니다. 실제 입금일을 입력하고 통장과 대조한 청구를 체크한 뒤 입금자명·메모를 확인합니다. 선택 합계와 확인창의 대상을 검토한 후 네를 누릅니다. 같은 입금일의 청구를 최대 100건까지 등록할 수 있습니다.

실장은 같은 화면의 원장 통장 확인 · 입금완료 명단에서 학생·비용·금액·입금일·입금자·확인 원장·확인 시각·메모를 봅니다. 원장 확인 명단 새로고침을 누르면 최신 결과를 확인합니다. 실장은 각 항목의 실장 확인 완료 버튼으로 확인자·확인 시각을 남깁니다. 원장도 같은 표시를 볼 수 있습니다. 입금 확인 취소 후 다시 등록한 내역은 실장이 새로 확인합니다. 현재 명단 엑셀 다운로드를 누르면 선택 월·비용·학생 검색이 적용된 명단을 .xlsx로 저장합니다. 등록은 원장만 가능하며 기존 전체 수납 내역도 함께 갱신됩니다. 일부 금액 입금은 전액 완료로 등록하지 말고 학원에서 별도로 확인합니다.

은행 자동 연동·자동 수납 처리는 없습니다. 문자 기능은 복사·문자앱 작성 방식이며, 유료 자동 대량 발송과 카카오톡 연동은 제공하지 않습니다.

08 월간일정과 생활규칙

승인 회원 / 원장 · 실장
업무 메뉴 → 월간일정 / 청라소개 → 청라 생활규칙

달력의 해당 날짜를 누르면 등록된 일정의 제목과 상세 안내를 확인할 수 있습니다. 생활규칙은 회원 서비스와 별개로 로그인 없이 볼 수 있는 공개 안내입니다.

  1. 01 월 · 날짜 선택
  2. 02 상세 내용 확인
  3. 03 닫기 · 원래 화면

1. 날짜로 일정 확인
