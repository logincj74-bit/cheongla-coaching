# 청라 설치형 앱 — 개발 시작본

기존 청라 웹앱과 동일한 Supabase 계정·승인·질문·공지·청라데스크 자료를 사용한다. 웹페이지를 원격 URL로 열지 않고 HTML·이미지·로그인 라이브러리를 앱에 포함한다. 기존 웹 배포에는 영향을 주지 않는다.

## 생성

Node 22 이상 환경에서 mobile 디렉터리에서 실행:

```sh
npm ci
npm run build
npm run add:android
npm run add:ios
npm run sync
```

Android Studio에서 `npm run android`, macOS와 Xcode에서 `npm run ios`로 열고 개발 기기에 설치한다. 플랫폼 생성 디렉터리는 아직 재생성 가능한 개발용 출력이다. 실제 네이티브 수정과 서명 구성을 확정하면 플랫폼 디렉터리를 Git으로 관리하도록 변경한다.

## 현재 포함한 연결

- 기존 화면·기능, 동일한 운영 DB 및 승인 규칙.
- Android 시스템 뒤로 가기: 앱 안의 메뉴 이력 이동, 첫 화면에서 최소화.
- 외부 HTTPS 링크는 네이티브 브라우저로 열기.
- 문제 사진에 사진 선택·사진 촬영 연결. 기존 사진 압축과 업로드 규칙 유지.
- 화면 안전 영역 및 인터넷 연결 안내.
- Supabase 라이브러리 앱 내 포함. CDN 없이 로그인 코드 시작 가능. 실제 회원 데이터 조회에는 인터넷 필요.

## 출시 전 필요한 작업

1. 앱 ID `kr.cheongla.academy`는 임시 개발 식별자다. 소유자·스토어 개발자 등록 후 최초 앱 생성 전에 확정한다.
2. Apple/Google 개발자 계정·조직 또는 개인 명의·서명·심사 준비. 결제·계약 동의·신원 확인은 소유자가 직접 처리한다.
3. 네이티브 APNs/FCM 푸시 토큰 저장·권한·발송·로그아웃 해제 구현. Web Push의 구독과 전달 방식은 그대로 사용할 수 없다. 지금 시작본은 해당 버튼을 숨기고 앱 내 알림함만 사용한다. 실제 OS 푸시가 완성되었다고 설명하지 않는다.
4. `npm run sync`가 iOS Info.plist의 사진·카메라 권한 목적 설명을 설정한다. 실제 사용 권한과 코어·포함 SDK의 개인정보 매니페스트를 최종 앱에서 확인한다.
5. Android/iOS 실기기에서 로그인 유지, 모든 역할, 사진 선택/촬영, 전화·문자·외부 링크·비공개 사진, 뒤로 가기와 알림 검증.
6. 회원 탈퇴/계정 삭제 요청과 처리 기능, 공개 개인정보처리방침, 고객지원 주소, 신고/차단 등 실제 게시판 심사 요구 검토·구현. 개인정보 보존 기준은 학원 운영자가 확정해야 한다.
7. 앱 아이콘·시작 화면·스크린샷·스토어 설명·연령 등급·데이터 안전성/개인정보 표시를 실제 동작과 일치하도록 준비.
8. 개발자 계정 유형에 따른 테스트 요건 충족, 서명된 AAB/iOS 아카이브 생성과 심사 제출. 아직 설치 파일·스토어 등록·심사 승인은 완료하지 않았다.

개인정보·서버 비밀키·서명키를 저장소에 추가하지 않는다. 현재 config.js는 웹앱과 동일한 공개 Supabase 연결 정보다.
