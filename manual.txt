# 청라앱 이용 매뉴얼

2026년 10월 26일 · 웹앱 v1.9.30 기준

청라앱: https://logincj74-bit.github.io/cheongla-coaching/

앱 맨 아래의 **이용 매뉴얼**에서도 이 안내를 열 수 있습니다. 화면 상단에서 필요한 도시락 문자 단계로 바로 이동하거나, **인쇄 · PDF 저장**을 이용하세요.

이 문서는 실제 앱의 메뉴와 버튼 이름을 기준으로 작성했습니다. 로그인한 역할에 따라 메뉴가 달라집니다. 여기서 ‘관리자’는 학원 운영 담당 원장·실장을 뜻하지만, 원장 전용 권한은 따로 표시합니다. 관리자가 학생 대신 도시락을 신청하는 구조가 아닙니다. 학생이 신청하고, 관리자는 신청 현황·청구·입금을 관리합니다.

## 1. 처음 이용할 때: 가입·로그인·승인

### 이메일 또는 휴대전화번호로 가입

1. 첫 화면 상단의 **로그인하기**를 누릅니다.
2. **처음 이용하시나요? 가입 신청**을 누릅니다.
3. **로그인 · 가입 방식**에서 **이메일로 이용** 또는 **휴대전화번호로 이용**을 고릅니다.
4. 가입 구분을 재원생·재원생 학부모·교직원 중에서 선택합니다. 학생은 학생 이름, 학부모는 학부모 본인의 이름을 씁니다. 학부모는 재원 중인 자녀 이름도 입력합니다.
5. 이메일 방식은 이메일과 연락받을 휴대전화번호를 입력합니다. 휴대전화번호 방식은 본인의 번호로 가입하며 이메일을 입력하지 않아도 됩니다.
6. 비밀번호와 비밀번호 확인을 같은 내용으로 두 번 입력합니다. 비밀번호는 8~128자입니다. 각 입력란 옆 **보기**를 누르면 해당 비밀번호를 볼 수 있고, **숨기기**를 누르면 다시 가려집니다.
7. **가입 신청**을 누릅니다. 이후 학원에서 신원·재원 여부를 확인하고 승인합니다. 학부모는 관리자가 자녀 연결까지 완료해야 자녀의 비용 내역을 확인할 수 있습니다.

휴대전화번호 입력 자체는 본인 인증이 아닙니다. 자동 인증 문자는 사용하지 않으며 학원에서 확인합니다. 이미 이메일로 가입했다면 새로 가입하지 말고 기존 이메일 계정을 이용하세요. 같은 번호를 여러 계정의 연락처로 쓰는 경우에도 서로 다른 사람의 계정을 임의로 합치면 안 됩니다.

### 다시 로그인하기

가입할 때 선택한 방식을 고르고, 이메일 또는 휴대전화번호와 비밀번호를 입력한 뒤 **로그인**을 누릅니다. 기존 이메일 가입자는 이메일 방식으로 계속 이용합니다. 가입 당시 로그인 번호와 연락받을 번호는 구분합니다. ‘내 전화번호 등록 · 수정’에서 연락처를 바꿔도 로그인 번호는 자동 변경되지 않습니다. 로그인 번호 변경·아이디 분실·비밀번호 분실은 학원에 문의하세요.

### 원장의 승인과 학부모 자녀 연결

경로: **로그인 → 업무 메뉴 열기 · 다른 업무로 이동 → 관리 업무 → 회원 승인 · 탈퇴 · 자녀 연결**

1. 회원 이름을 검색하고 해당 회원 항목을 펼칩니다.
2. 이름·연락처·재원 여부·역할을 확인합니다. 학생을 학부모로, 학부모를 학생으로 잘못 승인하지 않도록 주의합니다.
3. 역할과 승인 상태를 확인하고 **설정 저장**을 누릅니다. ‘앱 관리자’는 필요한 교직원에게만 부여합니다.
4. 승인된 학부모 항목에서 **연결할 재원생 선택 → 자녀 연결**을 누릅니다. 학생·보호자 관계를 확인한 뒤 최종 확인합니다.
5. 학부모 앱에 연결 완료 알림이 등록됩니다. 학부모가 알림을 누르면 **연결된 자녀** 화면으로 이동합니다.
6. 연결 직후 펼쳐진 **연결 완료 문자**에서 **학부모에게 연결 완료 문자 보내기**를 누릅니다. 기존 연결은 해당 자녀의 **연결 완료 문자 → 연결 상태·번호 확인 후 문자 준비**에서 다시 준비할 수 있습니다.
7. 문자 앱에서 수신번호와 내용을 확인하고 **전송**을 누릅니다.

실장에게 보이는 회원 관리 항목은 부여된 권한에 따릅니다. 승인·권한 부여·자녀 연결 버튼이 없는 계정은 원장에게 요청합니다. 신원 확인 없이 이름만 보고 자녀를 연결하면 다른 학생의 비용 정보가 노출될 수 있습니다.

## 2. 누구에게 어떤 메뉴가 보이나요?

| 이용자 | 청라데스크의 주요 메뉴 | 담당 업무 |
|---|---|---|
| 원장·실장 | 일일 학습계획표 확인 / 외부 수업 · 출결 예외 일정 / 내 전화번호 등록 · 수정 / 학원비 안내 / 도시락 신청 현황 / 모의고사 공지등록 · 신청명단 / 응시료 안내 / 청구 · 입금 관리 / 공지 등록 · 관리 / 문의 확인 · 답변 | 학습계획표·외부 일정 확인, 신청 현황·청구·입금·환불 관리, 학부모 문자, 상담 답변 |
| 학부모 | 일일 학습계획표 / 외부 수업 · 출결 예외 일정 / 내 전화번호 등록 · 수정 / 납부 · 입금 확인 / 문의사항 | 자녀 학습 기록 열람·외부 일정 확인, 청구·환불 조회, 실제 입금 후 알리기, 상담 문의 |
| 학생 | 일일 학습계획표 / 외부 수업 · 출결 예외 일정 / 내 전화번호 등록 · 수정 / 도시락 신청 / 모의고사 신청 / 문의사항 | 학습계획표·외부 일정 작성, 본인 신청과 신청완료 확인, 상담 문의 |

학원비·도시락비·모의고사비의 청구 문자와 청구 알림은 연결된 학부모에게 안내합니다. 학생에게 비용 청구 메뉴를 표시하지 않습니다. 학부모가 입금 알림을 남기면 원장·실장에게 업무 알림이 전달됩니다. 관리자에게 업무 현황이 보이는 것과 학부모에게 청구 알림을 보내는 것은 별개입니다.

원장 전용 기능에는 상담 · 신규 등록카드, 회원 강제 탈퇴·계정 통합, 시험·신청서의 영구삭제, 원장 통장 확인 명단 등록 등이 있습니다. 실장에게 원장 전용 버튼은 표시되지 않습니다. 게시글은 작성자가 자신의 글을 수정·삭제할 수 있고, 원장은 관리 권한으로 다른 글도 삭제할 수 있습니다.

## 3. 청라소개

경로: **첫 화면 → 청라소개**

**원장 인사말**에서 교육 방향을, **청라 상징 · CI**에서 로고의 의미를, **최근 3개년 입시실적**에서 실적을 확인합니다. **청라 모습**은 시설을 살펴보는 메뉴이고, **청라 생활 규칙**은 학생이 반드시 지켜야 할 생활·학습 기준입니다. 소개는 로그인 없이 볼 수 있습니다.

하위 메뉴를 누르면 해당 소개의 처음부터 읽습니다. 접힌 설명은 눌러 펼치고 다른 설명을 선택하면 이전 설명은 접힙니다. 생활 규칙 이미지는 눌러 확대하고 다시 누르거나 닫기 동작으로 원래 화면으로 돌아갑니다. 첫 화면으로 돌아갈 때는 **← 청라 첫 화면** 또는 하단 **청라 첫 화면**을 사용합니다.

## 4. 청라소식

### 원장 공지

경로: **청라소식 → 원장 공지 → 전체 공지 / 재원생 공지 / 학부모 공지**

교육 방향·원장 전달 사항을 확인합니다. 학생은 본인 대상 공지와 전체 공지를, 학부모는 학부모 대상 공지와 전체 공지를 봅니다. 원장 공지와 청라데스크의 실장 업무 공지를 구분해 확인하세요. 직원은 작성 화면에서 공지 대상과 채널을 확인한 뒤 저장합니다.

### 월간일정

경로: **청라소식 → 월간일정**

월을 선택하고 날짜를 누르면 해당 날짜의 기록이 표시됩니다. 원장·실장은 일정 제목·시작일·종료일·시간·구분·공개 대상·내용을 확인해 등록하고, 관리 버튼에서 수정·삭제합니다. 시험 자체의 삭제·복원과 달력에서만 삭제한 일정의 복원은 구분합니다. 학생·학부모는 공개 대상에 맞는 일정을 확인합니다.

### 입시 뉴스·자료실

경로: **청라소식 → 입시 뉴스** 또는 **자료실**

직원이 올린 글을 읽고, 첨부파일 이름이나 다운로드 버튼을 눌러 파일을 받습니다. 자료실은 **입시요강 / 기출 자료 / 학습 자료 / 각종 양식**으로 찾을 수 있으며 학습 자료는 과목으로도 좁힐 수 있습니다. **제목·내용 검색**을 이용하고, 글을 읽은 뒤 **☷ 목록보기**로 목록 처음으로 돌아갑니다.

원장·실장은 **글 등록 · 관리**에서 제목·안내 내용·자료 분류·공개 상태를 확인한 뒤 **저장하기**를 누릅니다. 첨부파일은 파일당 최대 20MB, 게시물당 최대 5개입니다. 관련 주소는 필요할 때만 입력하며 https://로 시작해야 합니다. 저장이 막히면 관련 주소 입력란과 파일 용량을 먼저 확인하세요. 공개 글은 로그인하지 않은 방문자도 볼 수 있으므로 개인 성적표·연락처 등 개인정보를 공개 자료로 올리지 않습니다.

## 5. 청라 Q&A

### 재원생·학부모 상담 문의

경로: **청라 Q&A → 재원생·학부모 상담 문의** 또는 **청라데스크 → 문의사항**

제목·내용을 작성하고 **공개 / 비공개**를 선택합니다. 비공개 문의에는 자물쇠 표시가 있으며 비밀번호 4자리를 입력하고 **질문 등록**을 누릅니다. 원장·실장 등 권한이 있는 직원이 답변하고, 작성자는 자신의 문의와 답변을 확인하거나 추가 질문을 남깁니다. 비밀번호를 입력했다고 다른 회원의 비공개 문의를 열람할 수 있는 것은 아닙니다.

### 비재원생·학부모 신규 상담 문의

경로: **청라 Q&A → 비재원생·학부모 신규 상담 문의**

신규 학생·학부모는 로그인 없이 문의할 수 있습니다. 성함·회신 전화번호·문의자 구분·공개 여부·제목·내용을 입력하고 개인정보 안내에 동의한 뒤 등록합니다. 공개 요청 글은 관리자 검토 후 게시됩니다. 비공개 문의는 공개 목록에 내용을 노출하지 않습니다. 원장·실장은 같은 메뉴의 관리자 목록에서 접수 내용을 확인하고 답변합니다.

전화·문자 상담 가능 시간은 **오전 8시~오후 11시**입니다. 본문에 불필요한 개인 정보나 타인의 정보를 쓰지 않습니다.

## 6. 청라데스크: 도시락 업무 전체 순서

이 절은 관리자·학부모·학생이 함께 읽되 각 단계의 담당자를 구분합니다. 세 문자는 목적이 다릅니다.

| 순서 | 누가 누구에게 | 보내는 내용 | 출발 위치 |
|---|---|---|---|
| ① 신청 접수 안내 | 원장·실장 → 학부모 | 학생의 점심·저녁 신청 개수. 아직 입금 안내가 아님 | 도시락 신청 현황 → 학생 이름 → 학부모 · 도시락 신청완료 안내 |
| ② 청구·입금 안내 | 원장·실장 → 학부모 | 정산된 금액·납부기한·계좌·입금 방법 | 학생의 월말 도시락비 청구를 저장·게시한 뒤 청구 안내 문자 보내기 |
| ③ 입금 확인 완료 | 원장·실장 → 학부모 | 학원이 실제 통장을 확인했다는 내용 | 청구 · 입금 관리 → 해당 도시락비 → 입금 확인 처리 후 입금완료 문자 보내기 |

**앱 알림은 서버에 등록되지만, 휴대폰 문자는 자동 발송되지 않습니다.** 각 문자 버튼으로 문자 앱을 열고 마지막 **전송**을 눌러야 합니다. 카카오톡 자동 발송은 연결되어 있지 않습니다. 컴퓨터에서 문자 앱이 열리지 않으면 청라앱을 학원 휴대폰으로 열거나 문구를 복사해 학원 휴대폰에서 보냅니다. 앱은 문자 버튼을 눌렀다는 이유만으로 발송·도착 완료라고 기록하지 않습니다.

### 6-1. 관리자가 월별 신청서를 먼저 개설

경로: **관리자 로그인 → 청라데스크 → 도시락 신청 현황 → 신청 월 → 관리자 · 월별 신청서 설정**

1. 신청받을 월을 선택합니다. 청구를 안내하는 월과 식사하는 월이 다를 수 있으니 확인합니다. 예를 들어 10월 말에 11월 식비를 안내할 때 신청 월은 11월입니다.
2. 제출기한, 1식 가격, 비고를 입력합니다. 1식 가격은 현재 7,500원이며 업체 단가 변경 시 확인 후 수정합니다.
3. **이 월의 신청서 저장**을 누릅니다. ‘학생용 신청서 양식 보기’는 관리자용 미리보기입니다. 원장·실장은 자신의 식사를 신청하지 않습니다.

### 6-2. 학생이 본인 도시락을 신청

경로: **학생 로그인 → 청라데스크 → 도시락 신청**

1. 신청 월·제출기한·본인 이름을 확인합니다.
2. 원하는 날짜의 점심·저녁을 각각 체크합니다. 상단 수량과 예상 금액이 계산됩니다.
3. 필요한 개인 비고를 적고 **도시락 신청**을 누릅니다. 체크만 하고 나가면 저장되지 않습니다.
4. **신청완료** 표시와 점심·저녁 개수를 확인합니다. 0개 제출 확인창이 뜨면 의도한 제출인지 다시 확인합니다.
5. 제출기한 내 추가 신청은 체크 후 **변경 내용 저장**으로 반영합니다. 이미 제출한 식사는 앱에서 직접 해제할 수 없습니다.

학부모 앱에는 도시락 신청 메뉴가 없습니다. 학생 신청이 접수되면 관리자가 신청 현황과 업무 알림에서 확인합니다.

### 6-3. 관리자 → 학부모: 신청완료 문자 보내기

경로: **청라데스크 → 도시락 신청 현황 → 신청 월 선택 → 신청 명단 · 월말 도시락비 청구 → 학생 이름 펼치기 → 학부모 · 도시락 신청완료 안내**

1. 학생 이름을 펼쳐 점심·저녁 날짜와 수량이 맞는지 확인합니다.
2. **신청완료 안내 문자 준비**를 누릅니다. 서버가 신청서 최신 상태와 연결된 승인 학부모를 확인합니다.
3. 문자 내용과 수신자를 확인합니다. 학생 이름·신청 월·점심·저녁·총 개수가 자동으로 들어갑니다.
4. **○○ 학부모에게 신청완료 문자 보내기**를 누릅니다.
5. 휴대폰 문자 앱에서 **전송**을 누릅니다. 이 문자는 접수 안내이므로 아직 금액 납부를 요구하지 않습니다.

연락처 등록 필요 표시가 나오면 먼저 학부모의 연락처를 확인합니다. 연결된 승인 학부모가 없다고 나오면 원장이 회원 관리에서 승인·자녀 연결을 확인합니다. 학생 전화번호로 대신 청구 문자를 보내지 않습니다. 신청서 변경 오류가 나오면 신청 현황을 새로고침하고 최신 수량으로 다시 준비합니다.

문자 예시: ‘11월 도시락 신청이 접수되었습니다. 홍길동 학생, 점심 8식·저녁 4식·총 12식. 식비와 납부기한은 정산 후 별도로 안내드립니다.’ 실제 버튼은 해당 학생의 수량으로 작성합니다.

### 6-4. 관리자가 월말 도시락비 청구를 저장·게시

경로: **같은 학생 이름 항목 → 월말 도시락비 청구**

1. 현재 신청 금액을 확인합니다. 예를 들어 점심 8식·저녁 4식이면 12식 × 7,500원 = 90,000원입니다. 이 수치는 설명용 예시입니다.
2. **납부기한**을 입력합니다.
3. 전월 취소분 등 차감액은 **정산 조정액**에 음수로 입력합니다. 예를 들어 7,500원 차감은 -7500입니다. 추가 금액은 양수로 입력합니다.
4. **납부 안내 · 정산 사유**에 필요한 설명을 적고 최종 청구 금액을 확인합니다.
5. 처음에는 **월말 청구 내용 저장**, 기존 청구를 고칠 때는 **청구 내용 수정·저장**을 누릅니다.
6. 새로 불러온 같은 학생 항목을 다시 펼쳐 저장 금액과 기한을 확인합니다. 저장만 하면 아직 초안입니다.
7. **청구 확인 후 학부모에게 게시**를 누르고 확인창에서 **네**를 누릅니다. 학부모 앱의 납부·입금 확인에 게시됩니다.

‘신청이 변경되었습니다’라고 표시되면 최신 신청 수량으로 청구를 다시 저장한 뒤 게시합니다. 이미 입금한 청구는 임의로 덮어쓰지 말고 정산을 확인합니다. 청구 저장·게시만으로 은행 송금이나 문자 발송이 일어나지 않습니다.

### 6-5. 관리자 → 학부모: 청구·입금 안내 문자 보내기

가장 통일된 경로: **청라데스크 → 청구 · 입금 관리 → 청구 기준 월 → 비용 종류 ‘도시락비’ → 학생 이름 검색 → 확인 → 해당 학생 청구 펼치기**

1. 식사 신청 월을 청구 기준 월로 고릅니다. 11월 도시락이면 11월입니다.
2. 비용 종류를 **도시락비**로 고르고 학생 이름을 입력한 뒤 **확인**을 누릅니다.
3. 미입금 청구 항목을 펼칩니다. **청구 안내 문자 보내기**를 누릅니다. 도시락 신청 현황의 저장·게시한 청구에서도 같은 문자 준비 기능을 사용할 수 있습니다.
4. 미리보기에서 식사 수량·단가·정산액·총액·납부기한·학원 계좌를 확인합니다.
5. **○○ 학부모에게 문자 보내기 → 문자 앱의 전송** 순서로 보냅니다.

학원 계좌와 예금주는 **해당 청구에 표시된 학원 계좌**를 기준으로 확인합니다. 실제 앱의 공통 계좌 설정과 일치하는지 대조하고 안내합니다. 입금자는 학생 이름으로 안내합니다. 청구를 고친 뒤에는 예전에 복사한 문구를 재사용하지 말고 문자 준비를 다시 누릅니다.

입금 확인 대기·입금 완료 상태에는 미납 독촉을 보내지 않습니다. 금액 재확인 상태는 먼저 통장과 청구를 대조합니다. 앱 알림은 학부모의 알림함에 표시되며 휴대폰 푸시는 기기 알림이 허용된 경우 수신합니다.

### 6-6. 학부모가 실제 입금 후 학원에 알리기

경로: **학부모 로그인 → 청라데스크 → 납부 · 입금 확인 → 자녀의 도시락비 청구**

1. 자녀 이름·비용 종류·신청 월·금액·계좌를 확인합니다. 학부모는 기본적으로 전체 청구를 볼 수 있으며, **전체 청구 표시 중 · 월별 보기**를 눌러 월별로 좁힐 수도 있습니다.
2. 은행에서 실제 송금합니다. 청라앱의 버튼이 송금해 주는 것은 아닙니다. 입금자명은 학생 이름으로 합니다.
3. 미입금 청구를 펼치고 **입금한 뒤 완료 알림 등록**에서 실제 입금자명·입금일·청구 금액을 확인합니다. 금액은 청구 전액 기준입니다. 일부 입금은 학원에 문의합니다.
4. 실제 입금했다는 확인에 체크하고 **입금완료 확인 · 학원에 알리기**를 누릅니다. 확인창에서 실제 입금 여부를 다시 확인합니다.
5. **학원 확인 대기** 상태가 표시되고 원장·실장에게 업무 알림이 전달됩니다. 이 단계는 학원의 입금 확인 완료가 아닙니다.
6. 문자 회신도 필요하면 같은 항목의 **학원에 입금완료 문자 보내기**를 누릅니다. 문자 앱에서 학생 이름·비용 종류·입금일·금액을 확인해 전송합니다. 이 버튼에는 앱에 등록된 학원 휴대폰 번호가 자동으로 입력됩니다.

잘못 남긴 앱 알림은 **잘못 등록한 입금 알림 취소**로 취소할 수 있습니다. 은행 송금 자체가 취소되는 것은 아닙니다.

### 6-7. 관리자: 실제 통장 확인 → 앱 입금완료 처리

경로: **청라데스크 → 청구 · 입금 관리 → 해당 월 · 도시락비 → 학생 검색 ‘확인’ → 확인 대기 청구 펼치기**

1. 학부모가 적은 실제 입금자명·입금일·금액을 읽습니다. 학생 이름과 입금자명이 다르면 주의해서 대조합니다.
2. 반드시 실제 학원 통장에서 입금 여부와 금액을 확인합니다. 학부모의 입금 알림만으로 완료 처리하지 않습니다.
3. 원장은 실제 입금일과 통장 입금자명을 확인하고 **통장 확인 · 입금완료**를 누릅니다. 확인창의 학생·비용·금액을 다시 확인한 뒤 **네**를 누릅니다.
4. 원장이 처리하면 입금완료 상태와 원장 통장 확인 명단이 함께 반영됩니다. 원장·실장은 같은 서버의 업무 현황을 봅니다. 학부모 앱에도 **입금 확인 완료**로 반영됩니다.
5. 실장이 처리하는 경우에는 권한에 따라 입금 확인을 처리합니다. 학부모가 등록한 확인 대기 요청을 처리하는 흐름과 원장 전용 통장 명단 등록은 구분합니다. 통장에서 확인하지 못한 입금은 원장에게 대조를 요청합니다.

입금이 확인되지 않으면 **입금이 확인되지 않나요?**를 펼쳐 학부모에게 전달할 사유를 적고 **확인 요청 보내기**로 재확인을 요청합니다. 중복 송금·일부 입금·환불은 자동 처리하지 않으므로 통장과 원장을 통해 별도 확인합니다.

### 6-8. 관리자 → 학부모: 입금 확인 완료 문자 보내기

경로: **같은 청구 항목이 ‘입금 확인 완료’로 바뀐 뒤 → 입금완료 문자 보내기**

1. 실제 앱 상태가 입금 완료인지 확인합니다. 아직 확인 대기라면 앞 단계를 먼저 마칩니다.
2. **입금완료 문자 보내기**를 누릅니다. 학부모 수신번호와 최신 수납 상태를 다시 확인합니다.
3. 문자에 자녀 이름·비용 종류·확인 금액·학원 확인일이 맞는지 봅니다.
4. **○○ 학부모에게 문자 보내기 → 문자 앱의 전송** 순서로 보냅니다.
5. 학부모는 자신의 **납부 · 입금 확인**에서 같은 완료 상태를 확인할 수 있습니다. 학부모에게 완료 알림이 등록되며, 알림을 누르면 해당 청구로 이동합니다.

원장과 실장이 같은 완료 문자를 중복 보내지 않도록 문자 발송 담당을 한 명으로 정하고, 실제 휴대폰 문자 앱의 발신 내역으로 확인하세요. 앱에는 문자 도착 여부를 확인하는 자동 기능이 없습니다.

### 6-9. 원장 통장 확인 명단을 실장이 확인

경로: **청구 · 입금 관리 → 원장 확인 명단 · 실장 확인 · 엑셀**

원장이 확인한 학생·비용·금액·입금일·입금자·확인 시각을 확인합니다. 새 자료가 보이지 않으면 **원장 확인 명단 새로고침**을 누릅니다. 실장은 해당 항목의 **실장 확인 완료**를 눌러 확인 사실을 남길 수 있습니다. 원장도 확인자와 확인 시각을 볼 수 있습니다. **현재 명단 엑셀 다운로드**로 선택 월·비용·검색 조건의 명단을 내려받습니다.

원장이 여러 건을 한꺼번에 처리할 때는 **여러 건 한꺼번에 입금 확인**을 펼쳐 실제 입금일을 입력하고 대조한 청구만 선택합니다. 금액 합계를 확인한 후 **선택한 명단 입금완료 등록**을 누릅니다. 같은 입금일 기준 최대 100건이며 일부 입금은 이 기능으로 전액 완료 처리하지 않습니다.

### 6-10. 도시락 취소 요청과 직원 처리

학생이 학부모에게 취소 연락을 부탁한 경우에도 반드시 **식사 전날까지 학원 휴대폰으로 전화 또는 문자**로 문의합니다. 당일 취소는 불가합니다. 학생·학부모 앱의 취소 문의 버튼은 전화·문자 앱을 열 뿐, 자동으로 식사를 취소하지 않습니다.

직원 경로: **도시락 신청 현황 → 해당 월 → 학생 이름 → 전화·문자 접수 · 식사 취소**

1. 학생·학부모의 연락 내용을 확인합니다.
2. 취소 날짜와 점심·저녁을 선택합니다.
3. 연락한 사람과 접수 내용을 기록합니다.
4. **접수 확인 · 식사 취소**를 누르고 최종 확인합니다. 당일·지난 날짜는 서버에서도 차단합니다.
5. 바뀐 신청 수량과 취소 이력을 확인합니다. 기존 청구 금액은 자동으로 바뀌지 않으므로 차감·환불 내용을 별도 정산하고, 필요하면 다음 청구의 정산 조정액에 반영한 뒤 새 안내를 보냅니다.

## 7. 청라데스크: 학원비 안내

관리자 경로: **청라데스크 → 학원비 안내 → 청구 월 → 학생 등록 정보와 납부 안내 관리**

1. 재원생을 선택하고 학원비 유형·최초 등록일·월 기본 원비를 확인합니다.
2. **등록 정보 저장**을 누릅니다. 월 기본 금액은 재수생 450,000원 / 재학생 200,000원 / 윈터·썸머스쿨 610,000원 / 공시생 350,000원입니다. 별도 금액이 필요하면 해당 유형을 선택합니다.
3. 계산 기준과 납부기한을 입력합니다. 윈터·썸머는 시작일·종료일·학교 등교 등 제외 날짜를 정확히 입력합니다. 기본 원비 610,000원과 별개로 일별 계산은 하루 20,000원을 사용합니다. 주말도 이용 기간에 포함되며 제외할 날은 별도로 지정합니다.
4. 예약금 100,000원을 차감할 때는 실제 통장 입금을 확인한 뒤 예약금 확인 항목을 선택합니다. 같은 스쿨 시즌에 중복 차감하지 않습니다.
5. **초안 계산·저장**을 누른 뒤 아래 학생별 청구 금액·기간·기한을 확인합니다.
6. **학부모에게 게시**를 누릅니다. 초안 저장만으로는 학부모에게 보이지 않습니다.
7. **청구 · 입금 관리**에서 비용 종류 **학원비**를 선택해 청구 문자 → 입금 확인 → 입금완료 문자를 보냅니다. 버튼과 순서는 도시락비와 같습니다.

입력만 지울 때는 안내 새로고침·초기화 기능을 이용하고, 저장한 청구 자체를 삭제하는 것과 구분합니다. 기존 게시 청구를 고칠 때는 먼저 게시 취소와 수납 상태를 확인하세요. 등록 정보를 저장해도 이미 만든 청구 금액이 저절로 바뀌는 것은 아닙니다.

## 8. 청라데스크: 모의고사 공지등록 · 신청명단

### 원장·실장이 시험을 먼저 등록

경로: **청라데스크 → 모의고사 공지등록 · 신청명단**

시험 구분은 **대성 더 프리미엄 / 시대인재 서프 / 한국교육과정평가원 6월 / 한국교육과정평가원 9월 / 기타**입니다. 구분·제목·시험일·신청 마감·내용·게시 상태를 입력하고 **시험 저장**을 누릅니다. 학생이 바로 신청해야 하면 **신청 열기** 상태로 저장합니다. 초안으로 저장한 시험은 학생 신청 대상이 아닙니다. 기존 시험 카드는 **시험 수정**으로 고칩니다.

### 학생이 신청

경로: **학생 로그인 → 청라데스크 → 모의고사 신청**

시험 구분과 시험일·마감을 확인하고 **모의고사 신청**을 누른 뒤 확인창에 응답합니다. **신청완료** 표시를 확인합니다. 마감 전 취소는 **신청 취소**, 취소 후 재신청은 **다시 신청**입니다. 학부모에게는 신청 메뉴가 보이지 않습니다.

### 관리자가 명단 확인

시험 카드의 **신청 명단 보기**를 누르거나 아래 **모의고사 신청 명단**에서 시험을 고릅니다. 학생 이름·신청완료·미신청·취소 상태를 확인하고 필요하면 명단을 내려받습니다. 같은 시험 구분이라도 시험일이 다르면 다른 회차입니다.

## 9. 청라데스크: 응시료 안내

경로: **청라데스크 → 응시료 안내**

1. 응시료 구분과 시험일·회차를 고릅니다. 시험이 없으면 먼저 모의고사 공지등록에서 등록합니다.
2. **응시료**를 직접 입력하고 납부기한·안내 문구를 적습니다. 금액은 고정이 아니며 이전 시험 금액이 맞는지 반드시 확인합니다.
3. **응시료 설정 저장 → 신청자 안내 초안 생성** 순서로 진행합니다.
4. 학생별 응시료·시험일·기한을 확인하고 **학부모에게 게시**를 누릅니다. 신청 취소·신청 정보 확인 필요로 표시된 학생은 먼저 신청 상태를 확인합니다.
5. **청구 · 입금 관리 → 비용 종류 ‘모의고사비’**에서 청구 안내 문자와 입금완료 문자를 보냅니다. 청구 기준 월은 **시험이 있는 월**입니다.

학부모는 **납부 · 입금 확인**에서 모의고사비를 확인하고 실제 입금 후 학원에 알립니다. 학생에게 응시료 청구 문자·청구 알림을 보내지 않습니다.

## 10. 청라데스크: 공지 등록 · 관리 / 문의 확인 · 답변 / 내 연락처

**공지 등록 · 관리**는 실장 업무 공지 채널입니다. 출결·생활·도시락·모의고사·납부 등 운영 안내를 등록합니다. 공지 대상이 전체인지 학생인지 학부모인지 확인하세요. 원장의 교육 공지는 청라소식의 원장 공지와 구분합니다. 중요한 개별 청구는 일반 공지에 개인정보를 쓰지 말고 해당 비용 청구 기능으로 안내합니다.

**문의 확인 · 답변**에서 회원 문의를 펼쳐 내용을 확인하고 답변을 남깁니다. 신규 비회원 문의는 청라 Q&A의 신규 상담 메뉴 관리자 목록에서 처리합니다. 학생·학부모는 **문의사항**에서 자신의 문의와 답변을 확인합니다.

**내 전화번호 등록 · 수정**에서 본인의 문자 안내용 연락처를 확인·저장합니다. 학생 계정에는 학생 번호, 학부모 계정에는 학부모 번호를 씁니다. 연락처를 바꾸어도 로그인 아이디는 자동 변경되지 않습니다. 관리자는 업무 메뉴의 **회원 연락처**에서 학생·학부모 이름이나 번호를 찾아 확인할 수 있습니다. 교직원의 개인 연락처 목록을 학생·학부모에게 공개하지 않습니다.

## 11. 영단어 찾기 · 내 단어장 / 나의 MBTI 학습법

**영단어 찾기 · 내 단어장**에서 영어 단어를 입력하고 **뜻 찾기**를 누릅니다. 뜻·품사·제공된 발음기호를 확인합니다. 실제 뜻이 적은 단어는 뜻이 5개보다 적을 수 있습니다. 로그인 후 단어장에 저장하고 복습합니다. 로그인을 바꾸면 자신의 단어장인지 확인하세요.

**나의 MBTI 학습법**에서 본인 유형을 선택·저장하고 유형별 학습 안내를 읽습니다. 학습법은 공부를 점검하는 참고 자료이며 개인별 상담·실제 성과와 함께 활용합니다. 유형 선택이 저장되지 않으면 로그인·승인 상태를 확인하고 새로고침합니다.

## 12. 청라 찾아오시는 길 / 전화·문자 문의

경로: **첫 화면 → 청라 찾아오시는 길**

로그인 없이 위치·주소·안내를 확인합니다. 지도나 길찾기 연결은 학원 인터넷 차단 설정에 따라 외부 지도 서비스가 열리지 않을 수 있으므로 방문자는 자신의 휴대폰에서 확인합니다. 메인 화면 하단 **전화 문의**는 전화 앱, **문자 문의**는 학원 휴대폰 번호가 입력된 문자 앱을 엽니다. 상담 가능 시간은 두 문의 모두 **오전 8시~오후 11시**입니다. 문자 전송 버튼은 문자 앱에서 직접 누릅니다.

## 13. 알림·계정 복구·삭제와 복원

### 알림 받기와 바로 열기

상단 **알림함 → 알림 제목 또는 바로 열기**를 누르면 해당 글·신청·청구로 이동합니다. 로그인하지 않았다면 로그인 후 이어서 엽니다. 삭제된 내용이나 권한이 바뀐 내용은 안내 문구를 확인합니다. 새로고침으로 최신 내용을 불러오세요.

업무 메뉴의 **알림 · 푸시 설정**에서 **푸시 알림 켜기**를 누르고 기기 권한을 허용합니다. 아이폰·아이패드는 홈 화면에 추가한 청라앱에서 설정합니다. 앱에서 켰더라도 기기의 알림 차단·집중 모드·네트워크 상태에 따라 푸시 수신이 달라질 수 있습니다. 운영체제 알림을 강제로 항상 켜 둘 수는 없습니다. 중요한 업무는 앱 알림함과 실제 업무 목록을 함께 확인합니다.

### 계정 복구와 탈퇴

로그인 화면의 **아이디 찾기 / 비밀번호 찾기**는 학원 문의 안내를 엽니다. 가입 당시 번호로 본인을 확인한 뒤 원장이 기존 아이디를 안내하거나 임시 비밀번호를 발급합니다. 임시 비밀번호로 로그인하면 새 비밀번호를 두 번 입력해야 합니다. 이메일·휴대전화번호 계정 모두 기존 기록을 유지하는 복구를 우선하며 새 계정을 반복 가입하지 않습니다.

본인 탈퇴는 **업무 메뉴 → 내 계정 · 회원탈퇴**에서 안내를 확인하고 동의·최종 확인을 거칩니다. 원장은 회원 관리에서 본인 확인과 사유를 남겨 강제 탈퇴·이용 중지를 처리할 수 있습니다. 중요한 작업의 확인창에서 **아니오**를 누르면 진행하지 않습니다.

### 휴지통과 영구삭제

도시락 휴지통: **도시락 신청 현황 → 신청 월 → 휴지통 · N건**. 원장은 신청서를 복구하거나 영구삭제할 수 있습니다. 영구삭제한 신청서는 복구할 수 없으며 입금·수납 이력은 별도로 보존합니다.

시험 휴지통: **모의고사 공지등록 · 신청명단 → 삭제한 시험 · 복원 / 영구 삭제**. 원장은 시험을 복원하거나 영구삭제할 수 있습니다. 영구삭제하면 시험·신청 내역은 복구할 수 없습니다. 입금 증빙이 있는 응시료는 별도 보관하고 학부모의 납부 확인에도 남습니다. 입금 확인 대기 건은 먼저 확인 또는 반려 처리합니다.

실장·학생·학부모에게 원장 전용 영구삭제 권한은 없습니다. 시험 등록 정보와 연결된 일정은 별개인 경우가 있으므로, 달력에서만 삭제한 일정은 월간일정에서 확인합니다.

## 14. 일이 막힐 때 먼저 확인할 것

| 증상 | 먼저 확인할 내용 |
|---|---|
| 학생에게 신청 메뉴가 없음 | 학생 역할·승인 상태·로그인 계정. 학부모 계정에는 신청 메뉴가 없습니다. |
| 학부모에게 청구가 없음 | 승인·정확한 자녀 연결·청구 게시 여부·신청 월 또는 시험 월·필터. 초안은 학부모에게 보이지 않습니다. |
| 문자 버튼이 없음 | 관리자 계정인지, 최신 신청·청구인지, 게시 여부, 연결된 승인 학부모, 납부 상태. 신청 접수 문자와 청구·입금완료 문자의 위치는 다릅니다. |
| 문자 앱이 열리지 않음 | 휴대폰에서 이용하거나 문구를 복사해 학원 휴대폰에서 전송합니다. 앱 버튼만 눌러서는 실제 발송 완료가 아닙니다. |
| 입금했는데 완료가 아님 | 학부모의 알림은 확인 요청입니다. 학원이 실제 통장을 대조한 뒤 완료 처리해야 합니다. |
| 금액 재확인 표시 | 신청 변경·청구 변경·실제 입금액·기존 수납액을 대조합니다. 확인 전 미납 문자를 보내지 않습니다. |
| 삭제 후 항목이 다시 보임 | 같은 이름의 다른 월·다른 시험인지, 복원 여부, 최신 목록인지 확인합니다. |
| ‘다른 화면에서 변경’ 오류 | 새로고침하고 최신 신청·청구·입금 상태로 다시 처리합니다. 이전 화면의 금액으로 문자를 보내지 않습니다. |

운영 권장: 신청 현황 확인과 문자 발송 담당, 실제 통장 확인 담당을 정해 두세요. 원장이 통장 확인을 등록하면 실장이 같은 명단을 확인하고 완료 문자를 발송하는 식으로 역할을 나누면 중복 작업이 줄어듭니다.

## 15. 학원 인터넷에서 청라앱이 열리지 않을 때

인터넷 차단 업체에는 아래 필요한 경로의 접속 허용을 요청합니다. 다른 인터넷 사이트를 모두 개방하는 요청이 아닙니다. HTTPS(TCP 443), WSS, JSON·JS·CSS·이미지·첨부파일 다운로드와 소개 영상 재생을 확인합니다.

```text
[필수]
https://logincj74-bit.github.io/cheongla-coaching/*
[학원 관리자가 확인한 운영서버 HTTPS 주소와 하위 경로]
[동일 운영서버의 WSS 연결 주소]
https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2

[청라 내부 영상·대표 사진]
https://cheongla-winter-2027.logincj.chatgpt.site/assets/*
https://cheongla-winter-2027.logincj.chatgpt.site/videos/*
```

영단어 사전 파일은 청라앱과 같은 주소에서 불러옵니다. 외부 사전 사이트를 추가 개방할 필요는 없습니다. 지도·인스타그램·블로그 등 외부 사이트는 이 목록에 포함하지 않습니다. 앱 외부 푸시는 기기·브라우저의 푸시 서비스 접속 상태에도 영향을 받으므로 학원 차단망에서 실제 수신 여부를 별도로 확인합니다.


## 16. 일일 학습계획표 — 학생 작성·학부모 열람·관리자 확인

위치: **청라데스크 → 일일 학습계획표**. 원장·실장 화면에서는 **일일 학습계획표 확인**입니다.

1. 학생은 학습 날짜를 선택합니다. 이름은 로그인한 학생 본인으로 연결됩니다. 좌석번호는 필요할 때 입력합니다.
2. 국어·수학·영어·탐구에 교재, 범위, 학습계획을 씁니다. **＋ 계획 추가**로 과목마다 여러 계획을 넣을 수 있습니다.
3. 아침에는 **계획 · 변경 내용 저장**으로 저장합니다. 저장된 기록은 작성 중 상태이며 연결된 학부모와 관리자가 볼 수 있습니다.
4. 하원 전 각 계획에 **○ 계획 / ✓ 달성 / △ 일부 달성 / × 미실행**을 선택합니다. 과목별 실제 공부한 시간을 **분** 단위로 입력합니다. 1시간 30분은 90분입니다.
5. 결석·지각·자리 비움 횟수, 자기 만족도와 셀프 총평을 입력하고 **하원 전 제출**을 누릅니다.
6. 제출하면 연결된 학부모와 원장·실장 알림함에 안내됩니다. 알림의 바로 열기로 해당 날짜·학생의 기록을 확인합니다.
7. 관리자는 같은 메뉴에서 학생과 날짜를 선택하고, 제출된 기록 아래 **관리자 확인 · 총평 → 확인 표시 남기기**를 누릅니다. 학생과 학부모에게 확인 완료가 표시되고 알림도 전달됩니다.
8. 학생이 다시 수정·저장하면 기존 관리자 확인은 해제됩니다. 수정 후 다시 제출하고 확인받습니다.

상단에는 월요일~일요일의 **주간 실제 학습시간**과 과목별 합계가 자동 표시됩니다. 저장한 입력값의 합계이며 앱이 집중시간이나 출석시간을 자동 측정하는 것은 아닙니다. 학부모는 연결된 자녀만 열람하며 대신 작성하거나 수정할 수 없습니다.

## 17. 외부 수업 · 출결 예외 일정

위치: **청라데스크 → 외부 수업 · 출결 예외 일정**.

1. 학생이 **＋ 외부 수업·출결 예외 일정 작성**을 엽니다.
2. 적용 시작일·종료일을 정합니다. 매주 반복되는 요일을 선택하고 학원·과외명 또는 예외 사유, 지각·외출·조퇴·결석 유형을 선택합니다.
3. 외출·복귀 시각은 이동시간까지 포함합니다. 예를 들어 수업이 19:00∼21:00이고 왕복 이동을 각 15분으로 잡는다면 18:45∼21:15로 적습니다.
4. 여러 일정은 **＋ 일정 추가**로 작성합니다. 기존 일정 변경 시 비고에 변경 사유를 남깁니다.
5. **일정 제출 · 변경 저장**을 누르면 연결된 학부모와 관리자에게 공유·알림됩니다.
6. 학부모는 해당 일정을 읽고 **자녀의 외부 일정 확인**을 누릅니다. 관리자는 학부모 확인 표시를 확인할 수 있습니다.
7. 관리자는 필요한 보호자 확인 전화를 진행하고 **보호자 확인 전화 · 접수 메모**에 내용을 적은 뒤 **확인 표시 남기기**를 누릅니다. 학부모의 앱 확인과 관리자의 접수 확인은 각각 표시됩니다.
8. 학생이 일정 내용을 수정하면 이전 관리자·학부모 확인이 해제됩니다. 다시 제출하고 관리자에게 변경 사실을 알려 주세요.

학부모의 앱 확인은 필요한 보호자 확인 전화를 대신하지 않습니다. 외부 일정 기록만으로 실제 등원·하원 여부가 자동 확인되지는 않습니다. 이전 달부터 이어지는 반복 일정도 적용 기간이 겹치는 달에 표시됩니다.

## 18. 상담 · 신규 등록카드와 일일 생활시간표

**상담 · 신규 등록카드**는 **청라소식 → 원장 공지 아래**에 있습니다. 영어원장·수학원장·원장만 열람·작성·수정하며, 실장·학생·학부모 화면에는 표시하지 않습니다.

- 상담·등록 구분, 상담일, 학생 이름·생년월일·주소·연락처·학교와 학년, 보호자 성함·관계·연락처를 기록합니다.
- 등록일·학원 수업시간·계열·내신 및 수능등급·선택과목·상담 세부 내용을 기록할 수 있습니다.
- 아직 가입하지 않은 신규 상담자도 카드 작성이 가능합니다. 이미 승인된 학생이라면 재원생 계정을 선택해 연결할 수 있습니다. 이 선택은 학부모 자녀 연결이나 회원가입 승인을 대신하지 않습니다.
- **등록카드 저장**으로 보관합니다. 조회 월을 선택해 목록을 보고 이름으로 검색하거나 **수정**을 누릅니다.
- 원장은 삭제 확인 후 휴지통 이동, 복구, 영구 삭제를 할 수 있습니다. 영구 삭제는 복구할 수 없습니다.

**일일 생활시간표**는 **청라소개 → 청라 생활 규칙 아래 → 일일 생활시간표**에 있습니다. 로그인 없이 월~토·일요일 교시별 시간을 확인합니다. 운영 변경일은 월간일정과 공지를 함께 확인합니다.

## 19. 모의고사 취소 후 환불 처리·학부모 안내

신청은 학생 본인 계정에서 진행합니다. 학부모가 취소를 요청하는 경우 학원으로 문의하고 담당 관리자가 신청 명단에서 취소를 처리합니다. 앱에서 신청 취소만 했다고 자동으로 환불 송금되는 것은 아닙니다.

1. 관리자는 **청라데스크 → 모의고사 공지등록 · 신청명단**에서 해당 학생의 시험 신청이 취소 상태인지 확인합니다.
2. 학원에서 실제 응시료 환불 송금을 합니다.
3. **청라데스크 → 청구 · 입금 관리 → 모의고사비 → 시험 월 → 학생 이름 → 확인**으로 청구를 찾습니다.
4. 청구 카드를 펼쳐 **모의고사 취소 · 환불 → 실제 환불 후 내역 등록**을 엽니다. 실제 환불일, 이번 환불금액, 학부모에게 안내할 사유를 적습니다.
5. **환불완료 등록 → 확인 창에서 네**를 누릅니다. 확인된 입금액을 초과하는 환불은 저장되지 않습니다. 여러 차례 나누어 환불한 내역과 누적 환불액을 함께 보관합니다.
6. 연결된 학부모의 **청라데스크 → 납부 · 입금 확인**에 **환불 완료 / 부분 환불 완료**, 환불일·금액·사유가 표시됩니다. 기존 입금 확인 기록도 남습니다. 학부모 알림함에도 안내되고, 관리자 업무 알림에도 처리 사실이 전달됩니다.
7. 관리자는 저장된 환불 내역의 **환불완료 문자 보내기**를 누릅니다. 최신 환불 내역과 연결된 학부모 연락처를 확인한 뒤 **학부모에게 환불완료 문자 보내기**를 누릅니다.
8. 휴대폰 문자앱에서 내용을 확인하고 **전송**을 누릅니다. 문자는 자동 발송이 아닙니다.

문자에는 학생·시험명·환불금액·환불일·사유와 함께 “학부모님께서는 입금된 환불 금액과 내역을 확인해 주시기 바랍니다. 확인이 어렵거나 금액에 차이가 있는 경우 학원으로 연락해 주시면 확인해 드리겠습니다.”라는 안내를 넣습니다.

환불 이력이 있는 입금 기록은 일반 입금 확인 취소로 지울 수 없습니다. 같은 시험을 환불 후 다시 신청하려면 학원에 문의해 주세요. 학부모는 환불 기록을 열람하며, 학생에게는 금융 청구·환불 내역을 표시하지 않습니다.
